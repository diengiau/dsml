## Introduction

This is an undergraduate course taught by Richard Dien Giau Bui at the National Chengchi University. Here is the course description, taken from the syllabus:

> This course introduces practical data science and basic machine learning for business students with little technical background.
>
> The first part develops core data skills such as working with data tables, cleaning data, visualization, and reproducible workflows, following the practical approach of **Coding for Economists** book. The second part introduces simple machine learning concepts and business applications in marketing, finance, and operations. The focus is on using data to support decision-making rather than on advanced mathematics or programming.
>
> The class is for undergraduate students with programming skills, basic mathematics, and are curious to learn about how machine learning can be applied for business decision-making.

Please read the full description at [Syllabus website](https://newdoc.nccu.edu.tw/teaschm/1151/schmPrv.jsp-yy=115&smt=1&num=301767&gop=00&s=1.html)
